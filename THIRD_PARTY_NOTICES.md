# Third-party code and notices

MilkO adapts the following source-preservation modules and their relevant tests
from [MilkJ](https://github.com/Bigsy/milkj), commit
`b6c2c7fabc3579b5ba05cd22dd583f3399524812` (frontend `0.1.26`):

- `source-preserving-sync`, `source-alignment`, `block-merge`, `markdown-blocks`,
  `block-index`, `sequence-align`, and the large-Markdown test fixture.
- Find/replace, outline, heading-anchor and HTML-preview modules and tests.
- Proofing extraction, normalization, dictionary, controller and Harper engine
  modules and tests. MilkO adds a local optimized-WASM worker and lazy lifecycle.

They live in `src/markdown/`, `src/proofing/` and the corresponding editor modules.
Changes include MilkO names, host-neutral comments/callbacks, lifecycle cleanup,
local preferences/worker integration and a fixture adjustment for corrected list spacing.
MilkJ's MIT copyright and permission notice are in [licenses/milkj-MIT.txt](licenses/milkj-MIT.txt).
MilkJ's transport and plugin entry point were not copied.

`types/vendor/orca-frame.d.ts` and `orca-host.d.ts` are unchanged official author
declarations from Orca commit `3a4fe5ac38598b4d02680cb835b362946ca9c5a4`, matching
installed version `1.4.251`:

- [Frame declaration](https://github.com/stablyai/orca/blob/3a4fe5ac38598b4d02680cb835b362946ca9c5a4/resources/plugins/types/orca-frame.d.ts)
- [Host declaration](https://github.com/stablyai/orca/blob/3a4fe5ac38598b4d02680cb835b362946ca9c5a4/resources/plugins/types/orca-host.d.ts)

Orca's MIT notice is in [licenses/orca-MIT.txt](licenses/orca-MIT.txt).

Milkdown/Crepe and the production dependency tree are covered in
[licenses/dependencies.txt](licenses/dependencies.txt), generated by
`pnpm license:collect`. This conservatively includes dependencies that bundling may
eliminate. Missing notice files make the collector fail for review. The MIT notice
omitted from the published `remark-math` 6.0.0 package is retained in
[licenses/upstream/remark-math-6.0.0-MIT.txt](licenses/upstream/remark-math-6.0.0-MIT.txt),
from its matching upstream release commit. The version, source and SHA-256 are
pinned in [licenses/overrides.json](licenses/overrides.json); an upgrade requires a
new reviewed notice entry.

The build replaces lodash-es's legacy global lookup with `globalThis`
for Orca's content policy; it does not enable string evaluation.

Harper 3.0.0's full WASM is optimized with Binaryen 133 using `-Oz --strip-debug
--strip-producers`. The original SHA-256 is
`cb8aaa2a8618ffe770e4f1fb2a6b19f16c6c7ac7815dced8c2ff44cbfda48440`;
the optimized SHA-256 is
`64dba282a29b234fc6fcbd67c8198a5dc3524c75f5d5d85407d3078c0e623c95`
(15,967,589 bytes). This retains the complete module's interface and functionality.
The pinned tool downloads, their SHA-256 digests and cache verification are in
`scripts/binaryen.mjs`. Binaryen is a build tool and is not bundled with MilkO.

KaTeX's fonts are distributed as WOFF2, supported by the target Chromium version.
Unused WOFF/TTF fallbacks are omitted; the upstream font notices remain included.
